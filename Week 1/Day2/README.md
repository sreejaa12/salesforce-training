# Salesforce Platform Basics

## What is Salesforce Platform?
Salesforce Platform is a cloud-based application development platform that allows businesses to build, customize, and manage applications without handling infrastructure. It provides tools for CRM, automation, security, data management, and development using both configuration and coding.

## App
An App in Salesforce is a collection of tabs, objects, and features grouped together for a specific business purpose. It provides users with an organized workspace.

Example:
A College Admission App that contains student admissions related data.

## Object
An Object in Salesforce is similar to a database table used to store records.

Examples:
- Student
- Admission Application
- Department
- Faculty

## Tab
A Tab is the user interface entry point used to access an object or feature in Salesforce.

Example:
Student tab opens all student records.

## Configuration vs Coding

### Configuration (No Code)
Used when Salesforce provides built-in tools to solve the requirement.

Examples:
- Creating validation rules
- Building flows for automation

### Coding (Apex)
Used when complex custom logic is required beyond standard tools.

Examples:
- Custom approval logic
- Trigger-based automation for advanced business rules

## CRM Concepts in Salesforce Platform
CRM concepts from Day 1 fit into Salesforce Platform using objects and apps.

- Account → College / University
- Contact → Student
- Lead → Inquiry Student
- Opportunity → Admission Application

These objects can be grouped inside a College Admission App where users manage the full admission process.

## System Design (College Admission System)

### App Name
College Admission Management

### Objects Inside App
- Student Object
- Admission Application Object
- Department Object
- Faculty Object
- Payment Object

### User Interaction
Admission staff log into the app, review student inquiries, convert leads into student contacts, process applications, track payments, and manage admission progress.
