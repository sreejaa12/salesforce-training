# Day 8 - LWC Basics

## What is LWC?
Lightning Web Components (LWC) is Salesforce’s modern UI framework used to build fast, reusable, and lightweight web components using HTML, JavaScript, and CSS. It follows web standards and provides better performance compared to older frameworks.

## Why Salesforce Uses LWC
Salesforce uses LWC because it is faster, more efficient, and based on modern JavaScript standards. It improves UI performance, supports reusable components, and makes development easier and cleaner.

## Component Breakdown
Components used in this learning:
- Selector Component → Displays bike selection UI
- List Component → Shows available bikes
- Detail Component → Shows selected bike details
- Reusable Lightning components for modular UI building

## Frontend vs Backend Logic
Frontend logic handles the user interface, user interactions, and displaying data using HTML, CSS, and JavaScript.

Backend logic handles server-side processing, business rules, database access, Apex classes, and secure data handling.
