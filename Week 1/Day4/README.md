# Day 4 - Flow Builder and Automation

## What is Flow Builder?
Flow Builder is a Salesforce automation tool used to automate business processes without writing code. It helps users create workflows, collect data, update records, send emails, and perform actions automatically.


## Types of Flows

### Screen Flow
A Screen Flow interacts with users by showing screens where they can enter data.

Example:
Student admission form where users enter details.

### Record-Triggered Flow
A Record-Triggered Flow runs automatically when a record is created, updated, or deleted.

Example:
Automatically send an email when a student application is approved.


## 5 Automation Ideas for College Management System

1. Automatically send admission confirmation email to students.
2. Notify faculty when a new student is assigned.
3. Auto-update seat availability after admission.
4. Send fee payment reminders automatically.
5. Generate student ID after successful registration.


## Flow Diagram

        ↓

## Manual Process vs Automated Process

### Manual Process
- Takes more time
- Higher chance of human errors
- Requires repeated manual work

### Automated Process
- Faster execution
- More accurate
- Saves time and effort
- Improves productivity


## Reflection
Automation is important because it reduces repetitive manual work, improves accuracy, saves time, and helps organizations manage processes efficiently.
